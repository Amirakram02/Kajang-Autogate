# Kajang Autogate — GitHub Pages

## Before publishing
Replace `60123456789` with the real WhatsApp number in `index.html` and `script.js`.
Replace the placeholder phone, email, service information and any unverified statistics.
Add real photos to the `images` folder. Use `images/hero.jpg` for the hero image.

## Publish for free
1. Create a PUBLIC GitHub repository named `kajang-autogate`.
2. Upload every file and the `images` folder.
3. Open Settings → Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch `main` and folder `/ (root)`.
6. Save.

Your site will be:
https://YOUR-USERNAME.github.io/kajang-autogate/

No paid hosting is required.
